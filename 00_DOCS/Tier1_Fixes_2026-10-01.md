## 2. What each fix does, and why

**SPECS (2403, 2405, 2404).** Three new `gen_straight2` SPECs, built only from end modules that already exist.
- 2403 = JIC x JIC, bore step at the hex mid-plane. 2405 = female NPTF port x JIC. 2404 = ASME B1.20.3 male NPTF x JIC.
- 2403-LH is the **large-hex union**, not a left-hand thread. OMi calls it "Straight-Large Hex", Air-Way s63 "Large Hex Union",
  Brennan "MJ-MJ STRAIGHT LARGE HEX". It is folded into 2403 as rows, as the legacy builder already did.
- Against the tables the current masters were built from: 2403 and 2405 differ only in body-radius rounding (at most 0.00002 in)
  and in thread-feature settings (threads are suppressed in saved masters). The reference outlines are point-for-point identical.
- 2404 changes on purpose: the hand-built pipe end (a plain cylinder of pipe OD) becomes the library NPTF cone. Volume change per
  configuration: -0.00025 in^3 (-02) to -0.02475 in^3 (-32).
- Review fixes F1 and F2 changed 2404 (section 8): rows with one bore where the sources give two are HELD, and 2404-40-32 is now
  ASSUMED.

**5404N-06.** The -06 round nipple was blocked because the Air-Way bar (C 0.69) is only 0.0040 in (radius) above the thread crest
cone at the end of the thread. The check asked for 0.005.
- 0.005 is a hex-corner margin. A round bar is never hex-cut, so it only needs a real step.
- New rule for round bars: a step of at least 0.0025, half the 0.01 print step of Air-Way C.
- -12 (step 0.0005) and -16 (bar below the crest) correctly stay blocked; OMi sells neither.
- The bar stays at Air-Way 0.69. It is the only source for the bar; the pipe OD 0.675 would be an unsourced value.

**ORB-02.** The male -02 ORB end (5/16-24) is now in the ORB library. It comes from the 6408-02-O-SOLID review row (thread length 0.234,
groove root 0.250, groove width 0.063).
- The Brennan 6801-04-02-NWO-FG STEP confirms the thread length and the groove root.
- The groove width rests on Parker ORD-5700 alone.
- The same end is already built in the accepted 6408 master.

**6565-CAVITY.** On the double swivel 6565, each 37 deg seat cone used to run down to its apex on the axis. At -20 and -24 the two
apexes cross and the outline intersects itself.
- Now each seat cone stops at the through-bore radius and closes radially to the axis.
- Brennan 6500 swivel legs, all 10 sizes: the seat ends exactly at the bore, with no flat. The Brennan TFA catalog p.18 draws 6565
  the same way.
- Two new columns, `SWA_SEATENDR` / `SWB_SEATENDR` = D1/2 / D2/2. These are published bore radii, not new data.
- The 6 existing configurations are geometrically identical (OCP symmetric difference 0).

**ORBF-DEEPBORE.** When the through-bore is at least the port minor, the female ORB port now ends flat at the measured port depth,
with no 120 deg drill point. The bore carries on at the same diameter.
- The Brennan TFA catalog p.16 gives a through drill equal to the port minor on exactly these short reducers. Air-Way prints D = D3
  on the same rows.
- The old drill point reached or passed the male tip on -20-12-O, -20-16-O and -24-16-O.
- New column `ORBFB_DRILLANG@DRIVE` (60 or 90) on every 6404 / 6410 row, and a new per-configuration "ORB port bottom check" in the
  macro.
- All 41 old 6404 / 6410 configurations keep the same solid (OCP volumes identical).

**6802-E45.** Two parts.
- (a) The 45 deg locknut-reach check counted the JIC thread radius, which never reaches the ORB axis on a 45 deg elbow. The real
  reach is the hex-arm corner, AC x cos 45. Only the check changed; the 16 old configurations are cell-identical.
- (b) A corner neck trim, feature ORBTRIM. It is emitted only when a configuration needs it. No real row needs it today; it is proven
  with TEST values for 6802-32-32.

**NECK-6502.** On the 45 deg swivel elbow, the forged corner stood out of the swivel neck at -05 and -12.
- Brennan 6502-12-12-FG shows nothing outside the neck from the body face to the nut rear face.
- Two revolve features, NECKTRIM1 (cut) and NECKFILL1 (ring back to the neck), now turn the neck clear in every configuration.
  Where the corner stays inside the neck they change nothing.
- The rebuilt 6502-12-12 measures like Brennan's: nut face 1.500, body face 0.411, neck 0.417, nut rear face 0.453.

**SIZE-40.** The -40 JIC end (3-12) is measured on the Brennan 2404-40-32 STEP with a new extractor, `tools/measure/jicm.py`.
- The extractor reproduces the frozen 2403 chain exactly on 9 Brennan STEPs at -08, -14, -20, -24 and -32.
- MS33656J as printed differs at -40 (end length 1.109 vs 1.335). The Brennan geometry is used and the row is ASSUMED.
- A library-gap guard now skips a row with a clear message. Before, 2501 crashed with `KeyError: 40`.
- The four -40 rows stay blocked: the repo has no 2-1/2-8 NPT row. No value was invented.

**MEASURED-ENDS.** Blocked on data. A full search found no STEP carrying a -02 or -14 swivel, a female -03 JIC port or a female -02
ORB port (682 STEP files checked by file name and by STEP header).
- Staged readiness change: `tools/measure/swiv.py` can now read straights with a female pipe port, the Brennan 6600 tee and our own
  models (`--model`).
- The skip-reason text in `gen_tee.py` now names the missing size. No macro or table changes.

## 6. SolidWorks test plan

Everything below is a **dry run**. A dry run saves into `<I>/sw_tests/dryrun/<fix>/` and never touches `11_MASTERS`. Accepted masters
are only opened read-only and closed with discard.

### 6.1 Before you start

- SolidWorks 2026 must be running (it is SP4 since 2026-10-01; the control runs on SP4 reproduced the masters). Restart it first:
  the full set is 18 dry-run builds and 7 read-only sweeps of accepted masters.
- Close any open 6404, 6410, 6565, 6502, 6802, 2403, 2404, 2405, 2408, 5404N and 6405 master. Two parts with the same file name
  cannot be open at once.
- Close your VBA editor windows. Check free memory if a call hangs (CLAUDE.md gotcha).

### 6.2 How to run

From Git Bash: `sh tools/_out/tier1_20261001/integrated/sw_tests/run_sw_tests.sh` runs A0 and A. Add `test` to also run B.
- Outputs: `<I>/sw_tests/out/<call file>.txt` and the comparisons `cmp_*.txt` / `check_*.txt` there.
- Macro reports: `<I>/sw_tests/dryrun/<fix>/.../Build_<root>_report.txt`.
- Or run one call file at a time: `python sw_mcp/call.py @tools/_out/tier1_20261001/integrated/sw_tests/<file>.json`.
- Claude can run the same steps through the solidworks MCP tools.

Each real-data call file is the CLAUDE.md verify loop:
1. `run_macro` on `regen/after/<straight|tee>/Build_<root>_MASTER.bas` with `const_overrides`: `SAVE_PATH` and `REPORT_PATH` into
   `<I>/sw_tests/dryrun/<fix>/`, and `TABLE_PATH` = `regen/after/<straight|tee>/DesignTable_<root>_SW2.xlsx`.
   Check `report.fail` / `fail_lines` and the msgbox.
2. `sweep_configs` with the key dims: every configuration rebuilds, 1 solid body, sizes plausible.
3. `geometry` on the reference size and the extreme / new sizes: cylinder diameters, cone angles, plane offsets.
4. `screenshot`, several views plus a `Front Plane` section. Look at them.
5. Compare with the accepted `11_MASTERS` part.

Some call files lack an extreme size or the geometry step. Add those by hand (listed per root below):
`open_doc` the dry-run part (its `SAVE_PATH`), then `geometry` and `screenshot` with `section_plane` "Front Plane", then `close_doc`
with `discard_unsaved`.

To compare two sweeps: `python tools/_out/tier1_20261001/swtest/sweep_cmp.py <sweep A> <sweep B>`. It reads the first
`sweep_configs` block of each file. Tolerance 1e-5 by default.
