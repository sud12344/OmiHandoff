HOW THE BULKHEAD LEG IS BUILT (Brennan 2701-08-08-FG STEP, measured)
  hex arm -> round collar, dia = Air-Way O (STEP 0.875 vs O 0.88) -> JIC bulkhead end whose relief-to-tip length is
  Air-Way i2 (STEP 2.11 - 0.86 = 1.25 = i2), with the JIC thread run from the relief to the land (as on 2700/2705).
  ASSUMPTION: Air-Way K1 is read as the collar thickness (the STEP collar is 0.125 thick and is followed by a 0.125
  round shank at the thread diameter, which is not modelled). -LN configs ship with a locknut (not modelled).
