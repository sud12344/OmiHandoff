## Sources (rule: Air-Way first, then OMi, then Brennan marked BRENNAN)
- Air-Way prints none of these part numbers. It prints only the non-forged twin (e.g. 1502-8-8), or nothing for 2404-L-32. The exception is 1502-04-04-FG, which Air-Way does print. Forged and plain parts differ (they do here on flats / legs, see `$COMMENT`), so the twins' values are a cross-check only. Each target row's `$COMMENT` gives them.
- OMi's website file has no dimensions for these rows, except 2505-08-08-FG (row 793, already in the table) and 2404-40-40 (row 531, already in the table).
- So the source is the Brennan TFA catalog (cell, page, table, line_y cited per cell in `$PRP@AxialSource`). Each value was checked on the part's own STEP; all agree within 0.005 (`measure/`). Catalog and STEP are the same manufacturer, so they count as one source: DataStatus **ASSUMED**, `$PRP@DimSource` **BRENNAN**, and `[BRENNAN-ONLY 2026-10-21]` at the start of AxialSource.
- Column pairings come from the siblings already in the tables (wave 1/2/3). For 6603 the pairing is M2 = nut-face crossing, M4 = nose tip, M = branch tip. This is confirmed three ways: on the own STEP, by the 6606 pairing, and by Air-Way's plain 6603-6-6-6.
- End details come from the end library, as on every sibling (Q-TRANSFER-ENDLIB): tap drills FPT, NPTF / NPSM / JIC majors, ENDL[40]. Brennan's own port drills (0.718 / 0.578) are noted, not used.
- **2505-08-08-FG**: the PORTDEPTH cell is marked with the 2026-10-20 single-cell convention, `$PRP@DimSource` BRENNAN + `[BRENNAN-CELL 2026-10-21: PORTDEPTH@BORE]`. Note: the shipped PORTDEPTH cells of 5503 / 5505-04-04-FG carry no BRENNAN marker. Pick one convention.
- Small STEP-vs-catalog differences: 6603 / 6606 -06 nose tips 0.865 on some legs vs catalog 0.870; one nut face 1.255 vs 1.250 (Brennan's model is asymmetric). The catalog value is kept.
