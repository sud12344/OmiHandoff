ORFS model type - Brennan STEP files needed (2026-10-16)
========================================================
SHAPE ONLY (user 2026-10-08: "Brennan 3D files for SHAPE only"): no dimension is taken from these files.
- You download them. Brennan's part numbers are the OMi FS part numbers.
- Save each one as 09_STEP_FILES/BRENNAN_<part number>.stp, e.g. 09_STEP_FILES/BRENNAN_FS2403-08-08.stp.
- Every part number below is printed in Brennan's ORFS catalog (07_RAW_EXTRACTS/brennan_catalogs/ORFS Catalog.pdf; page given), so
  Brennan sells it.
- None is in 09_STEP_FILES yet: on 2026-10-16 no FS file was among the 153 files there.
- Why each is needed: PLAN.md in this folder (end entries FSM / FSSW / FSBH, questions Q-FS-*).

QUESTIONS FOR YOU (first)
  S1. Download part 1 (9 pilots) now, and parts 2 and 3 only after the pilots are measured and their extractors pass? Recommended. The
      earlier STEP lists worked the same way: pilots first, the rest after the pilot passes.
  S2. Also download the Air-Way 3D models of part 5?

  S3. Get BRENNAN_FS2408-08 (part 4) only if the FS2408 plug is to be built with Air-Way's hole (PLAN Q-FS2408-HOLE).

   Every pilot is a row with dimensions of its own master, so it also serves that master's closed loop.

                                  - new tools/measure/fsm.py must read both ends the same.
                                  - measures: face, O-ring groove (must fit the Air-Way FS4000-08 O-ring: I.D. 0.489, W 0.070),

  P3  FS2701-08-08-FG        p8   MALE BULKHEAD END (FSBH) -08: face-seal nose, thread run over Air-Way i2 1.44, collar d17 1.00 x
